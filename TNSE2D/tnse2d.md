# Two-dimensional flow past a cylinder

## Boundary conditions
- Channel walls, cylinder: No slip (u = 0, v = 0)
- Traction-free outflow: $\partial u/\partial n = 0$, $\partial v/\partial n = 0$, $p = 0$
- Parabolic inflow: $u = 4U_{max}y(H-y)/H^2$, $v = 0$

# Parameters
- Cylinder diameter: $D = 0.1$, centered at $(0,0)$
- Channel height: $H = 0.41$
- Channel length: $L = 2.5$
- Inflow velocity: $U_{max} = 1.5$
- $\nu = 0.001$
- $\Delta t = 0.01$
- $T_{end} = 53.0$
